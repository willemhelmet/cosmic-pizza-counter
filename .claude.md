# Pizza Fortune Teller 3D - Project Overview

## Project Description
An immersive 3D web experience where users build custom pizzas by dropping physics-enabled ingredients onto a spinning pizza base. Each ingredient's placement and physics interaction affects a mystical AI-powered fortune reading. Built with Three.js, Rapier3D physics, and TypeScript.

## Tech Stack
- **Three.js**: 3D graphics and rendering
- **Rapier3D**: Physics simulation
- **TypeScript**: Type safety
- **Vite**: Build tooling
- **Claude API**: Fortune generation
- **GSAP**: Animations

## Ingredient System
The app includes 95 unique ingredients across three categories:
- **Normal** (15): Standard pizza toppings (cheese, pepperoni, mushrooms, etc.)
- **Bizarre** (75): Absurd items (dust bunnies, forgotten passwords, toy dinosaurs, etc.)
- **Special** (5): Unique physics properties (brain, eyeballs, ice cream, etc.)

Each ingredient has:
- Custom physics properties (mass, bounciness, friction)
- Visual representation (emoji in UI, 3D mesh in scene)
- Fortune traits that affect the mystical reading

## Physics System
- Realistic gravity and collision detection
- Each ingredient has unique physics properties
- Ingredients bounce, collide, and stack naturally
- "Shake" feature to redistribute toppings
- Physics chaos affects fortune readings

## Fortune Generation
The fortune system analyzes:
- Total collision count
- Chaos score (how messily ingredients landed)
- Symmetry score (ingredient distribution)
- Stack height (tallest ingredient tower)
- Ingredient combinations and clusters
- Lucky numbers derived from physics data

## API Integration
The FortuneGenerator class is designed to work with Claude API but currently uses a mock implementation. To enable real API:
1. Add valid API key to `.env`
2. Uncomment API call in `FortuneGenerator.ts`
3. Consider implementing a backend proxy for security
